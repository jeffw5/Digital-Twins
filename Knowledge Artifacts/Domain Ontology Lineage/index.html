Domain Ontology Lineage

The holarchy of the core, read left to right from parent to child. BFO 2020 and the OBO Relations Core sit above the unifying ontology, ontology-core-domain, which declares the root classes, the 21 shared relations and the SHACL rules every other ontology builds on. Each core taxonomy (taxonomy-core-*) is an OWL file generated from its core vocabulary (vocabulary-core-*) and imports the unifying ontology; the core ontologies (ontology-core-*) and the governance ontologies (ontology-core-governance-*) import it and the taxonomies they specialise; ontology-core-bundle loads the whole set. There are only vocabularies, taxonomies and ontologies, each named by the convention. Edges come from the files: owl:imports, root declarations, rdfs:subClassOf inheritance across files, BFO anchors, dc:subject grounding and SKOS mappings. Select any box to trace what it inherits and what inherits from it; double-click, or use its arrow, to open it in its vocabulary, hierarchy or ontology view.
