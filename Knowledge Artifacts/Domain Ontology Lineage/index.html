Domain Ontology Lineage

How the Domain Reference Model (ontology-core-domain) stands on BFO 2020 and the OBO Relations Core, and how vocabularies, taxonomies, core ontologies and governance overlays build on it. There is no separate upper ontology: the reference model is the foundation every other domain ontology imports. This is the corrected v1.1 set: the TM Forum SID, RAN and ThinkHome payloads are removed and every lineage issue from v1.0 is resolved. All 20 core SKOS vocabularies (888 concepts) are now in the lineage, each grounding its taxonomy or core ontology. Edges come from the v1.1 files: owl:imports, dc:subject links, vocabulary-to-taxonomy grounding, subclass anchors and SKOS mappings. Select any node to trace its ancestry and descendants, then open its vocabulary, hierarchy or ontology explorer from the panel. The small arrow on each node, or a double-click, opens that module’s main explorer directly.
